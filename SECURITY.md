# Security

Security reports are evaluated against current public PeerLink X releases.

Do not put sensitive vulnerability details in public issues.

GitHub private vulnerability reporting should be enabled before publication. If
it is not enabled, a dedicated private reporting contact must be configured
before publishing security-sensitive release announcements.

Supported releases are the current public release and any later maintained
public release line explicitly documented by the project.

For the current security model and known limitations, see `SECURITY_MODEL.md`.
